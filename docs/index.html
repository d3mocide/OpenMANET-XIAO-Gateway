XIAO HaLow Gateway — Web Flasher

Flashes the OpenMANET-S3-Client firmware onto a Seeed XIAO ESP32-S3 + Wio-WM6180 (HaLow) node. Works in Chrome/Edge over USB - no software to install.

This flashes firmware with placeholder configuration (open HaLow uplink, default local Wi-Fi credentials). See "After flashing" below to set your real values - nothing here bakes in your Wi-Fi/HaLow credentials, they're entered later over the device's own local network, not typed into this page.
Your browser doesn't support Web Serial. Use Chrome or Edge on desktop. Web Serial is only available over HTTPS (this page should already be HTTPS via GitHub Pages).

Before flashing

  1. Plug the XIAO ESP32-S3 in via USB-C.
  2. Click "Connect & Flash" above and pick the device's serial port when your browser asks.

After flashing

  1. The device boots and starts its own Wi-Fi access point (default SSID xiao-gateway, password openmanet - see the firmware's defaults if these have changed).
  2. Connect your laptop or phone to that Wi-Fi network.
  3. Browse to http://192.168.50.1/ - the on-device config page.
  4. Set the real HaLow uplink SSID/security/passphrase (open/OWE/SAE only - see the Pi-side reference for what the mesh Pi expects) and your own local Wi-Fi SSID/password, then Save and Reboot.

Regulatory/country code

The HaLow radio's legal channel list is set at build time, not from this page or the on-device config UI. If the firmware served here doesn't already have your country configured, it won't associate - see sdkconfig.defaults's CONFIG_HALOW_COUNTRY_CODE in the repo.
